# 🧪 Potion Maker

A fun beginner-friendly Python mini-project that randomly creates a magical potion by selecting an ingredient and its magical effect.

## 🛠️ Technologies Used

* Python
* Random module

## ✨ How It Works

The program randomly selects:

* 🧪 One magical ingredient
* ✨ One magical effect

using Python's `random.choice()` function.

## ▶️ How to Run

Make sure Python is installed, then run:

```bash
python potion_maker.py
```
